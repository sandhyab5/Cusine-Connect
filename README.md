# Cusine-Connect-
🍽️ Cuisine Connect

Recipe Recommendation System Based on Ingredients

📌 Project Overview

Cuisine Connect is a smart recipe recommendation system that suggests suitable recipes based on the ingredients provided by the user.
The main goal of this project is to reduce food waste, save time, and help users discover new dishes using available ingredients.

This project uses data preprocessing, text cleaning, and machine learning techniques to match user-input ingredients with recipes from a dataset.

🎯 Objectives

Recommend recipes based on user-input ingredients

Clean and preprocess raw recipe data

Improve matching accuracy using NLP techniques

Provide fast and relevant recipe suggestions

🧠 How It Works

User enters ingredients

Ingredients are cleaned and processed

Dataset recipes are preprocessed

Matching recipes are identified

Top relevant recipes are displayed

🗂️ Dataset

File name: recipe.csv

Source: Web-scraped recipe data

Contents:

Recipe name

Ingredients

Cooking instructions

⚠️ Note: This project does not use Recipe1M+, Food-101, or personalized user data.

🔧 Data Preprocessing Steps

The following preprocessing techniques are applied:

Tokenization

Lowercase conversion

Stopwords removal

Stemming

Removal of unwanted words

Removal of measurements (cups, tsp, grams, etc.)

Regex-based text cleaning

These steps improve ingredient matching accuracy.
